# Student Record Management System

A modular command-line Student Record Management System built with Python using Object-Oriented Programming principles, JSON-based persistence, runtime tenant isolation, and validation-driven data handling.

---

# Features

## Multi-Tenant Runtime Architecture

The system dynamically provisions isolated student registries using runtime execution identifiers:

```python
Student(objname)
```

Each execution context generates dedicated storage files, preventing data overlap across independent academic groups such as:

* FALL2026
* SPRING2026
* CLASS10
* SECTION_A

---

## Validation-Driven Data Integrity

The application validates all user input before persistence.

### Name Validation

* Alphabetic characters only
* Length restricted between 3 and 50 characters

### Auto-Increment Roll Numbers

Roll numbers are dynamically generated by scanning existing student records and incrementing the highest assigned identifier.

### Email Validation

* Structured email validation
* Maximum length constraints

### Phone Validation

* Decimal-only validation
* Exactly 11 digits required

---

## JSON-Based Persistent Storage

Student data is stored using lightweight JSON persistence.

Storage structure:

```text
StuData/
StuMarks/
```

This separation isolates:

* student biographical records
* academic marks data

---

## CRUD Operations

The system currently supports:

* Add Student
* Update Student Information
* Remove Student
* View All Students
* Add Marks
* Update Marks (in progress)

---

## Menu-Driven Console Interface

Interactive terminal-based operational workflow.

```text
1. Add Student
2. Update Info
3. Add Marks
4. Update Marks
5. Remove Student
6. See All Students
7. Exit
```
